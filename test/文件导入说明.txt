电压数据评估系统 - 文件导入使用说明
========================================

一、支持的文件格式
------------------
1. JSON (.json)
2. CSV (.csv)

二、JSON 文件格式
----------------
方式1：简单数组格式（推荐）
[128.5, 130.0, 131.5, 132.0, 133.0]

方式2：结构化格式
{
  "expectedVoltages": [128.5, 130.0, 131.5, 132.0, 133.0],
  "description": "这是一个示例"
}

方式3：其他字段名
{
  "voltages": [128.5, 130.0, 131.5],
  "values": [132.0, 133.0]
}

三、CSV 文件格式
---------------
方式1：单列数字（推荐）
128.5
130.0
131.5
132.0
133.0

方式2：带表头的多列（只取第一列）
Voltage,Description
128.5,正常电压
130.0,正常电压
131.5,正常电压

四、示例文件
------------
本目录包含以下示例文件：

1. example_voltages.json - 简单数组格式
2. example_voltages_structured.json - 结构化格式
3. example_voltages.csv - 简单CSV格式
4. example_voltages_with_headers.csv - 带表头的CSV格式

五、使用步骤
------------
1. 打开电压评估系统页面
2. 切换到"数据输入"标签页
3. 在"方式2：文件导入"区域选择文件
4. 点击"📂 导入文件"按钮
5. 系统会自动解析并加载数据
6. 继续进行评估

六、注意事项
------------
- 所有数值都会被解析为浮点数（对应电压数据的类型）
- CSV文件只解析第一列数据
- 非数字类型的值会被自动过滤
- 文件大小建议不超过10MB

七、与仿真数据的对应关系
----------------------
导入的预期数据类型（浮点数）与系统仿真输出的电压值类型完全匹配，确保评估计算的准确性。
