铁路轨道电路故障模拟系统 - CSS使用说明
================================================

一、CSS组织方式
--------------
本项目采用内嵌CSS方式，所有样式直接写在HTML文件的<style>标签内，不使用独立的CSS文件。

主要使用CSS的页面：
1. templates/index.html - 主页面
2. templates/time_series_generator.html - 时序数据生成页面
3. templates/register.html - 注册页面


二、配色方案
-----------
1. 主题色
   - 主色调：#3498db (蓝色) - 用于按钮、边框、标题等
   - 成功色：#27ae60 (绿色) - 用于成功提示、成功按钮
   - 错误色：#e74c3c (红色) - 用于错误提示、错误按钮
   - 次要色：#95a5a6 (灰色) - 用于次要按钮

2. 背景色
   - 页面背景：#f4f7fa (浅灰) 或 #121212 (深灰)
   - 内容区块：#000 (黑色) 或 #1e1e1e (深灰)
   - 输入框：#333 (深灰)
   - 结果卡片：#2a2a2a (中灰)

3. 文字色
   - 主要文字：#fff (白色)
   - 次要文字：#ccc (浅灰)
   - 提示文字：#999 (灰色)

四、布局技术
-----------
1. Flexbox布局
   - display: flex - 启用flex布局
   - flex-direction: column - 垂直排列
   - justify-content: center - 水平居中
   - align-items: center - 垂直居中
   - gap: 10px - 元素间距
   - flex-wrap: wrap - 自动换行

   示例：
   .form-row {
       display: flex;
       gap: 15px;
       margin: 15px 0;
       flex-wrap: wrap;
   }
   
   .form-col {
       flex: 1;
       min-width: 200px;
   }

2. Grid布局
   - display: grid - 启用grid布局
   - grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)) - 响应式列
   - gap: 15px - 网格间距

   示例：
   .section-grid {
       display: grid;
       grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
       gap: 15px;
       margin-bottom: 20px;
   }

3. 固定定位
   - position: fixed - 固定在视口
   - top: 0 / left: 0 - 定位位置
   - z-index - 层级控制

   示例：
   .floating-tabs {
       position: fixed;
       top: 50%;
       right: 20px;
       transform: translateY(-50%);
       z-index: 1000;
   }

八、CSS最佳实践
---------------
1. 重置样式
   * {
       margin: 0;
       padding: 0;
       box-sizing: border-box;
   }

2. 使用相对单位
   - padding, margin 使用 px
   - font-size 使用 px 或 em
   - 使用 max-width 和 min-width 实现响应式

3. 过渡动画
   - 为可交互元素添加 transition
   - 使用 ease 缓动函数
   - 过渡时间 0.3s 为宜

4. 层级管理
   - z-index: -1 (背景)
   - z-index: 1 (内容)
   - z-index: 1000 (悬浮窗)
   - z-index: 1500 (遮罩)
   - z-index: 2000 (侧边菜单)
   - z-index: 3000 (底部窗口)
   - z-index: 4000 (图表窗口)

5. 颜色使用规范
   - 统一使用 #3498db 作为主色调
   - 成功状态使用 #27ae60
   - 错误状态使用 #e74c3c
   - 背景色使用深色系（#000, #1e1e1e, #333）
   - 文字色使用白色系（#fff, #ccc, #999）


九、开发建议
-----------
1. 新增页面时，参考现有页面的CSS样式保持一致性
2. 使用相同的配色方案和布局方式
3. 为新组件添加 hover 状态和 transition 效果
4. 考虑响应式设计，添加媒体查询
5. 使用语义化的类名，便于维护
6. 添加适当的注释说明样式用途
