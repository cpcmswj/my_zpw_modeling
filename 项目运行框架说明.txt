
================================================================================
                        铁路轨道电路故障模拟系统 - 项目框架说明
================================================================================


一、项目概述
--------------------------------------------------------------------------------
这是一个基于Web的铁路轨道电路故障模拟系统，采用前后端分离架构：
- 后端：Python + FastAPI 提供API服务
- 前端：HTML + CSS + JavaScript 构建用户界面

--------------------------------------------------------------------------------

用户注册时的头像上传流程：

1. 用户选择图片
   ↓
2. JavaScript读取文件
   - FileReader API
   - 生成base64预览
   ↓
3. 用户提交注册
   ↓
4. FormData发送到后端
   - username (Form)
   - password (Form)
   - avatar (UploadFile, 可选)
   ↓
5. FastAPI接收
   - File(...) 接收文件
   - 检查文件是否存在
   ↓
6. 保存文件到uploads/
   - 文件名格式：{用户名}_{uuid}.{扩展名}
   - 确保uploads目录存在
   ↓
7. 保存用户信息
   - user_store.add_user(username, hashed_password, avatar_path)
   ↓
8. 登录时返回
   - 登录API返回 avatar_path
   - 前端保存到localStorage
   ↓
9. 显示头像
   - &lt;img src="/uploads/xxx.jpg"&gt;
   - 无头像时隐藏img元素

十、常见问题
--------------------------------------------------------------------------------

Q: 为什么upload目录是空的？
A: uploads目录用于存放用户上传的头像，只有用户注册并选择头像后才会有文件。

Q: 用户数据存在哪里？
A: 开发环境：内存存储（database.py SimpleUserStore）
   生产环境：Vercel Edge Config

Q: 如何启动服务器？
A: 运行: python start_server.py 或 python -m uvicorn main:app --port 8000

Q: 图表绘制使用什么库？
A: Chart.js，通过CDN引入：https://cdn.jsdelivr.net/npm/chart.js

Q: 密码如何安全存储？
A: 使用PBKDF2-HMAC-SHA256哈希算法，加盐迭代100000次
